很多视频都是纯黑背景+纯白字幕，这其实非常刺眼，为了解决这一痛点，我做了这个软件（AI辅助），适用于Windows平台，请点击页面右侧的【Releases】进行下载。

黑色半透明遮罩条（用于降低视频字幕亮度）：

1、双击exe文件就生成一个置顶的黑色矩形，可手动调整大小，可移动位置；

2、不透明度（可见度）默认35%，可调范围10%~100%，鼠标悬停在软件上用鼠标滚轮调节可见度，步进为5%；
